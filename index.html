Methodology and limitations

  1. Discover Firecrawl search and scrape tools through Composio MCP.
  2. Search for developer documentation and API references for each listed application.
  3. Prioritize URLs on the application's supplied domain and scrape a small number of pages.
  4. Apply conservative pattern-based extraction. Unsupported fields are labelled as unconfirmed.
  5. Prepare a 20-app human spot-check sample (two per category where possible), checking authentication, developer access and API type.

Search coverage is not exhaustive. Search-result absence does not establish that a product has no API, no MCP server or no developer program. API scope, plan restrictions, rate limits, terms and production readiness require direct confirmation.
